使用指引

① 三步接入

  1. 在「密钥」页创建并复制客户端 API Key（sk-…）。
  2. 确定接入地址：Base URL = http://<host>:2325/v1。
  3. 在「平台模型」页确认对外模型名（业务名或别名均可），按下方案例调用。

② curl 调用示例

查看可用模型：

curl http://localhost:2325/v1/models -H "Authorization: Bearer sk-你的密钥"

对话（非流式）：

curl http://localhost:2325/v1/chat/completions \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d '{"model":"smart-fast","messages":[{"role":"user","content":"你好"}]}'

对话（流式，SSE 增量输出，最后一块带 usage）：

curl http://localhost:2325/v1/chat/completions \
  -H "Authorization: Bearer sk-你的密钥" -H "Content-Type: application/json" \
  -d '{"model":"smart-fast","stream":true,"messages":[{"role":"user","content":"你好"}]}'

③ Python（OpenAI SDK）示例

from openai import OpenAI

client = OpenAI(base_url="http://localhost:2325/v1", api_key="sk-你的密钥")
resp = client.chat.completions.create(
    model="smart-fast",                                  # 平台模型名或别名
    messages=[{"role": "user", "content": "你好"}],
    # stream=True,                                       # 需要流式时打开
)
print(resp.choices[0].message.content)

④ 接入新供应商（5 步）

  1. 「供应商」页 → 新增供应商：填名称、Base URL、API Key（可填多把 Key 组成密钥池）。
  2. 点「获取模型列表」拉取上游目录，勾选要导入的模型。
  3. 「平台模型」页 → 新增/编辑平台模型，添加成员：选 供应商 › 模型，设权重（分流比例）与优先级（故障转移顺序）。
  4. 在平台模型列表点 ⚡测试 验证整条链路连通性。
  5. 把 Base URL + 密钥 + 平台模型名交给调用方，完成。

⑤ 模型测试与常见错误

平台模型列表每行的「测试」按钮会按真实调用链（成员选择 → 密钥池轮换 → 故障转移）发一条小消息，返回时延、tokens 与回复摘要；测试请求会计入统计。

常见错误速查：

  • 401 invalid_api_key：客户端密钥不对，去「密钥」页核对。
  • 404 model_not_found：模型名/别名拼错，或平台模型被停用。
  • 503 no_available_member：平台模型没有启用成员，或所有成员正在冷却。
  • 502 all_members_failed：上游全部失败，到「统计 → 最近请求」看具体上游错误。
  • 「日志」页可查全部请求记录；开启「设置 → 调试模式」后，每条日志可点「详情」查看请求/响应报文。
